Controls 
Left click / drag   select (Shift adds); a drag takes
                    combat units first, then turrets, then
                    everything else
Double-click unit   select all matching units on screen
Right click         move / attack / harvest / dock / charge /
                    build (on a building: set rally point)
Ctrl + right click  queue instead of replace
                    (Shift also works outside Firefox)
Action grid         M move, A attack, S stop, H harvest,
                    D unload, C recharge, X demolish (press
                    twice; sites refund fully), plus class buttons
                    (aimed ones: left-click a target; Ctrl
                    keeps aiming; right-click/Esc cancels)
Mouse wheel         zoom; middle-drag or arrows pan; Home resets
Build bar (bottom)  place a building; selected builders build it
                    (Ctrl/Shift + click places several)
Esc                 cancel aim / placement / deselect / docs
Ctrl+1..9, 1..9     set / recall group (press twice
                    quickly to centre on it)
Shift+1..9          add the selection to a group
Ctrl+A              select all units
F1 / F2             script docs / class designer
